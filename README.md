The Detailed Area Plan (DAP) is the official, government-approved master land-use and urban development plan for Dhaka and its surrounding regions, managed by the Rajdhani Unnayan Kartripakkha (RAJUK). I georeferenced a PNG file containing the image of the DAP area, and then digitized in ArcGIS Pro. And thus, the polygon shapefile of DAP area is created. Co-ordinate system WGS 1984 UTM 45N. Download the zip file and work in GIS software.
